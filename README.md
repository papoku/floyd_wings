# Floyd Wings and Grill

A React restaurant website built with Vite.

The website uses Floyd Wings and Grill's public brand, menu photos, address, and contact details.

## Run locally

This project uses Node 22 or newer. With nvm installed, run `nvm use` from this folder to select Node 22.

```sh
yarn install
yarn dev
```

Vite prints the local URL in the terminal. To create a production build, run `yarn build`.

## Deploy to GitHub Pages

The `Deploy to GitHub Pages` workflow builds and publishes the site when changes are pushed to `main` or `master`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The published site is available at `https://papoku.github.io/floyd_wings/`.

The landscape digital menu board is available at `https://papoku.github.io/floyd_wings/menu-board.html`.

The TV menu has three landscape screens: sandwiches, tacos/nachos/salads, and seafood. Use the arrow controls to preview screens; full-screen mode rotates every 15 seconds. Choose **Edit menu** to change text or prices, then **Save edits**. Saved edits stay in that browser on that TV. **Export TV pictures** downloads each screen as a separate 3840 × 2160 JPEG. Press Escape to leave full screen; use **Reset board** in edit mode to restore the original menu.

## Source
